Up2J - divers frameworks build upon Jakarta EE (JEE)

### [Up2LOV Core](https://github.com/up2jakarta/up2-divers/blob/master/up2lov-core/README.md)

Modern API for CodeList or List Of Values (LOV) manipulation.

``` xml
    <dependency>
        <groupId>io.github.up2jakarta</groupId>
        <artifactId>up2lov-core</artifactId>
        <version>1.6.2</version>
    </dependency>
```

### [Up2CSV Core](https://github.com/up2jakarta/up2-divers/blob/master/up2csv-core/README.md)

Modern API for mapping, validating and parsing flat-data to JavaBeans with fault tolerance ability.

``` xml
    <dependency>
        <groupId>io.github.up2jakarta</groupId>
        <artifactId>up2csv-core</artifactId>
        <version>1.6.2</version>
    </dependency>
    <!-- Optional JSR-303 Provider -->
    <!-- Optional CDI/IoC Provider -->
```

### [Up2CSV Format](https://github.com/up2jakarta/up2-divers/blob/master/up2csv-format/README.md)

Modern API for batch processing of CSV files for standard mode or multi-segments format.

``` xml
    <dependency>
        <groupId>io.github.up2jakarta</groupId>
        <artifactId>up2csv-format</artifactId>
```
